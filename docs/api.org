#+TITLE: jump-pad API

Generated from the route table by ~cmd/apidocs~. Do not edit this file
by hand, because the next run overwrites it. Run ~just apidocs~ after a
route changes.

* Open to everyone

No token. A visitor reaches these routes.

** ~GET /~

Serve the landing page. A path that no other route claims gets 404 here.

** ~GET /new-redirect~

Serve the redirect creation form.

** ~GET /new-paste~

Serve the paste creation form.

** ~GET /view/{id}~

Serve the highlighted read page for a paste.

** ~GET /admin~

Serve the admin page. The page itself is public, and its API needs the admin token.

** ~GET /static/config.js~

Answer with the resolved prefixes and the auth state as JavaScript, for the frontend.

** ~GET /static/~

Serve the stylesheet, the scripts, and the vendored files.

** ~GET /{slug}~

Send a visitor to the target URL of a slug.

| Field | Required | Meaning |
|-------+----------+---------|
| ~slug~ | yes | The short name in the path. |

** ~GET /pastes/{id}~

Answer with the raw content of a paste as plain text.

| Field | Required | Meaning |
|-------+----------+---------|
| ~id~ | yes | The paste id in the path. |

* Create token

These routes need the create token when ~auth_token~ is set. The token arrives in the ~X-Auth-Token~ header, or in a ~token~ query parameter.

** ~POST /redirects~

Create a redirect and answer with its final slug as plain text.

| Field | Required | Meaning |
|-------+----------+---------|
| ~slug~ | yes | Wanted short name. A taken name gets a numeric suffix. |
| ~target_url~ | yes | Full http or https URL to send the visitor to. |
| ~expiry~ | no | Empty for forever, or 1d, 1w, 1m, a future date, or a duration such as 72h. |

** ~POST /pastes~

Store a paste and answer with its final id as plain text.

| Field | Required | Meaning |
|-------+----------+---------|
| ~content~ | yes | The text to store. The cap is 500 KB. |
| ~slug~ | no | Wanted id. A random 12 character id takes its place when this is empty. |
| ~language~ | no | Language hint for syntax highlighting, such as python. |
| ~expiry~ | no | Empty for forever, or 1d, 1w, 1m, a future date, or a duration such as 72h. |

* Admin token

These routes exist only when ~admin_token~ is set, and they need that token in the ~X-Auth-Token~ header. A query parameter is not accepted, because a token in a URL reaches logs and history.

** ~GET /admin/api/items~

List every redirect and every paste, expired rows included. Pastes carry no content.

** ~GET /admin/api/pastes/{id}~

Read one paste with its content, whether it is expired or not.

| Field | Required | Meaning |
|-------+----------+---------|
| ~id~ | yes | The paste id in the path. |

** ~POST /admin/api/redirects~

Add a redirect. A taken slug gets a numeric suffix, and the answer names the final slug.

| Field | Required | Meaning |
|-------+----------+---------|
| ~slug~ | yes | Short name. An edit to a taken name answers 409. |
| ~target_url~ | yes | Full http or https URL. |
| ~expiry~ | no | Empty for forever, or 1d, 1w, 1m, a future date, or a duration such as 72h. |

** ~PUT /admin/api/redirects/{slug}~

Replace a redirect. A new slug renames the row, and every link to the old slug stops working.

| Field | Required | Meaning |
|-------+----------+---------|
| ~slug~ | yes | Short name. An edit to a taken name answers 409. |
| ~target_url~ | yes | Full http or https URL. |
| ~expiry~ | no | Empty for forever, or 1d, 1w, 1m, a future date, or a duration such as 72h. |

** ~DELETE /admin/api/redirects/{slug}~

Remove a redirect.

| Field | Required | Meaning |
|-------+----------+---------|
| ~slug~ | yes | The slug in the path. |
